# 🌟 Hello from Winnie | Interactive Live Clock & Showcase

A premium, highly interactive personal greeting page featuring backdrop glassmorphism styling, ambient glowing mesh backgrounds, dynamic clock/date mechanisms, and micro-interactions.

## 🔗 Live Demo

You can run and preview the live page directly on your local system:
👉 **[Launch Live Demo](file:///D:/wi/index.html)**

## ✨ Features

- **💎 Modern Glassmorphic Design:** Tailored color palette, high contrast, smooth shadows, and blurred backdrops.
- **🕒 Real-time Dynamic Clock:** Displays the current time (12-hour format with AM/PM indicators) and full calendar date (weekday, month, day, year).
- **🌅 Ambient Dynamic Greetings:** Automatically adjusts greeting badges based on the user's timezone hour (Morning, Afternoon, Evening, Night).
- **🌗 Responsive Theme Toggle:** Seamless dark/light theme switching with custom vector icons.
- **🎨 3D Interactive Tilt:** A custom vanilla JS hover effect that responds dynamically to mouse coordinates.
- **📱 Fully Responsive:** Beautiful layouts scaled for mobile, tablet, and desktop screens.

## 🚀 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/winnieshih1107/wi.git
   ```
2. Open `index.html` in your web browser, or use a local development server:
   ```bash
   # If you have Node.js / npx
   npx serve .
   ```

## 🛠️ Built With

- **HTML5:** Semantic layout design.
- **Vanilla CSS3:** Custom HSL variables, fluid gradients, keyframe animations, and backdrop filters.
- **Vanilla JavaScript (ES6+):** Lightweight DOM manipulation, 3D math projection for card tilt, and date/time polling.
